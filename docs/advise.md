# Agent Data-Collection Advice Guide

This guide instructs an advising agent how to read `summary.json` generated by `lerobot-check report` (optionally combined with user-provided real-robot per-subtask success rates), run `mix` and `suggest` to compute concrete projections, write a Chinese `advice.md`, and embed it back into the offline HTML report.

## Workflow

1. **Generate the baseline report and `summary.json`**:

   ```bash
   uv run lerobot-check report \
     --dataset-root /path/to/dataset \
     --group 原数据=0-120 \
     --group 补录=121-173
   ```

   By default this writes `index.html` and `summary.json` to:
   `<lerobot_root>/.xense-viewer/reports/<org>__<name>@<revision>/`.

2. **Read `summary.json`** and inspect every section (provenance, frame shares, fine windows, speed check, object pose coverage, sparse cells, pairwise offsets).

3. **Check provenance first**:
   - Inspect `provenance.has_unreviewed_agent` and `provenance.counts.agent`.
   - If `provenance.counts.agent > 0`, highlight at the top of `advice.md` that those rows have not yet been reviewed by a human in `xense-lerobot-viewer`, so numbers derived from them are provisional.

4. **Compute post-collection ratios with `mix`** (or exact frame arithmetic grounded in `summary.json` when simulating new single-stage episodes):
   - When comparing existing datasets or supplement repeats, run:

     ```bash
     uv run lerobot-check mix \
       --dataset-root /path/to/base --repeat 1 \
       --dataset-root /path/to/supplement --repeat 2
     ```

   - When projecting additional single-stage supplement episodes of an existing group, you may either run `mix` on the split CSVs/datasets or compute using the exact `mean_frames_per_episode` and `frames` from `summary.json` (and cite the exact `mix` output or `summary.json` fields).

5. **Generate next-batch object placements with `suggest`**:

   ```bash
   uv run lerobot-check suggest \
     --dataset-root /path/to/dataset \
     -n 20 \
     --seed 0 \
     -o /tmp/lerobot-check/suggestions.csv
   ```

   Always preserve the disclaimer that objects are sampled independently from sparse coverage bins and inter-object collisions are not checked.

6. **Write `advice.md` in Chinese** following the structure and grounding rules below (write outside the repository, e.g. in the report directory `<report_dir>/advice.md` or `/tmp/.../advice.md`).

7. **Re-run `report` with `--advice`** to embed the advice section (labeled **Agent 建议**) into `index.html`:

   ```bash
   uv run lerobot-check report \
     --dataset-root /path/to/dataset \
     --group 原数据=0-120 \
     --group 补录=121-173 \
     --advice /path/to/advice.md
   ```

## Grounding Rules (Strict)

- **Every number must be traceable**: every frame count, percentage, episode count, speed value, ratio, coordinate, yaw angle, and sparse-cell count written in `advice.md` must come verbatim from `summary.json`, `lerobot-check mix`, `lerobot-check suggest`, or user-supplied real-robot evaluation data. Do not invent or round away facts without showing the source metric.
- **Explicitly state missing real-robot metrics**: if the user did not supply per-subtask real-robot rollout success rates, state plainly in `advice.md` that no real-robot success rates are available for this run and that recommendations are based solely on dataset distribution, speed, and workspace coverage.
- **State data limitations**: if `contact`/`grasp` annotations are absent (for example, `annotator=converted` exports from `task_index`), note that fine windows only cover release tails `[max(start, end - fine_window_s), end)` and `event=grasp` objects have 0 samples until `contact`/`grasp` are annotated.

## Required Structure of `advice.md` (Chinese)

Write `advice.md` in clear, concise Chinese with four sections:

1. **数据前提与标注来源**：标注来源计数（`human` / `converted` / `agent`），是否存在未复核 `agent` 行，是否提供真机各阶段成功率，以及 `contact`/`grasp` 缺失对精细窗口与物体统计的影响。
2. **优先补采的 Subtask 与建议条数**：结合当前各 subtask 帧数、帧占比、精细窗口占比、单条平均帧数（以及真机成功率，如有），说明应补哪个 subtask、建议补采条数，并给出通过 `mix` 算出的补采后帧占比与精细窗口占比。
3. **下一批摆放建议**：总结 `objects[].coverage` 的稀疏比例与覆盖范围（对比原数据与补录组的覆盖差异），并引用 `suggest` 给出下一批重点摆放区域（XY 与折叠 Yaw），同时注明未检查物体间碰撞。
4. **采集与标注注意事项**：依据 `speed_check` 的未放慢比例、各臂速度比中位数与精细窗口占比，给出具体操作建议（例如在释放/接触前主动放慢、补齐 `contact`/`grasp` 标注以启用抓取阶段分析）。

## `summary.json` Schema Reference

`lerobot-check report` writes `summary.json` alongside `index.html` with the following top-level fields:

| Field | Type | Description |
| --- | --- | --- |
| `schema_version` | `int` | Schema version (currently `1`). |
| `task_name` | `str` | `name` from the task spec. |
| `fine_window_s` | `float` | Fine-window duration $\Delta$ in seconds. |
| `speed_ratio_threshold` | `float` | Threshold above which `fine_median / rest_median` is flagged as not slowed down. |
| `min_rest_speed_mps` | `float` | Non-fine median TCP speed (m/s) below which an arm is treated as idle. |
| `coverage_config` | `object` | Grid settings: `xy_bin_m`, `yaw_bin_deg`, `sparse_threshold`. |
| `provenance` | `object` | Aggregate annotation provenance: `total_rows`, `counts` (`agent`, `human`, `converted`), `has_unreviewed_agent` (`bool`). |
| `overall` | `object` | Combined frame/episode totals across all groups/datasets: `annotated_episodes`, `total_episodes`, `skipped_episodes_count`, `total_frames`, `total_fine_frames`, `total_fine_share`, and `subtasks[]` (each with `subtask`, `episodes`, `frames`, `frame_share`, `mean_frames_per_episode`, `fine_frames`, `fine_share_of_subtask`, `fine_share_of_total`). |
| `groups` | `list[object]` | Per-dataset or per-episode-group entries (`label`, `repo_id`, `revision`, `fps`, `arms`, `provenance`, `frame_shares`, `speed_check` including `flagged_episodes` and `flagged_records`, `skipped_objects_count`). |
| `speed_check` | `object` | Overall speed-check summary across all groups: `flagged_episode_count`, `flagged_arm_records`, `idle_arm_records`, and `by_arm.<arm>` (`active_episodes`, `idle_episodes`, `flagged_episodes`, `median_fine_mps`, `median_rest_mps`, `median_ratio`). |
| `objects` | `list[object]` | One entry per `task_spec.objects` item: metadata (`name`, `subtask`, `event`, `arm`, `yaw_symmetry_deg`), `sample_count`, `skipped_count`, summary stats (`x_m`, `y_m`, `z_m`, `folded_yaw_deg` with `min`/`max`/`mean`/`std`), `by_group.<label>` breakdown, and `coverage` (`total_cells`, `occupied_cells`, `sparse_cell_count`, `sparse_cell_share`, `ix_range`, `iy_range`, `num_yaw_bins`, `sparse_cells[]`). |
| `pairwise_offsets` | `list[object]` | Same-arm pairwise relative displacement stats: `object_a`, `object_b`, `arm`, `count`, `dx_m`, `dy_m`, `dist_xy_m` (`min`/`max`/`mean`/`std`). |
